## Avance del proyecto

1. Normalización en tercera forma normal.
2. Diccionario de datos.
3. Modelo relacional con notación Crow's Foot.
4. Diagrama de clases UML.
5. Diagrama de despliegue UML.
6. Prototipo navegable en HTML, CSS y Bootstrap.
7. Base de datos MySQL con sentencias DDL, datos de prueba y consultas DML.
8. Aplicación en CodeIgniter 4 con registro, inicio de sesión, bcrypt, sesiones y catálogo conectado a MySQL.

## Ejecución de la aplicación

1. Importar los archivos SQL de `07_base_datos` en MySQL.
2. Entrar a `08_aplicacion_era`.
3. Crear `.env` a partir de `env` y configurar la conexión a `era_db`.
4. Ejecutar `composer install`.
5. Ejecutar `php spark serve`.
6. Abrir `http://localhost:8080`.
